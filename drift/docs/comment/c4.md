# Executable Documentation Blocks in Drift

## Overview

Drift now supports executable code blocks inside documentation comments using the markers `@exc` and `.exc`.

This is the supported format:

```drift
/*
    This is documentation.

    @exc
        say "Hello"
        var x = 10
        say x
    .exc

    This is still a comment.
*/
```

## Rules

1. `/* ... */` is a normal documentation block.
2. The `@exc` marker starts an executable section inside that block.
3. The `.exc` marker ends the executable section.
4. All lines between `@exc` and `.exc` are treated as executable Drift code.
5. The `*` prefix is no longer used for executable lines inside comments.
6. The block comment may contain ordinary documentation text before and after the executable section.

## Example

```drift
/*
    This program demonstrates executable documentation blocks.

    @exc
        say "I"
        say "hate"
        say "c"
    .exc

    The lines above execute, but everything else here is just documentation.
*/
```

Output:

```text
I
hate
c
```

## Why this format exists

The old `*` convention mixed comment text and executable code in a confusing way. The new format separates documentation from executable code more clearly:

- plain lines inside the block are comments
- `@exc` starts code
- `.exc` ends code
- all executable lines are parsed normally by the interpreter

## Important note

The executable block is still inside a comment block, so it does not affect normal source flow outside the comment. It is only extracted and executed as a controlled code section.
